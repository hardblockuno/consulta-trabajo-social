# Reglas para futuras iteraciones

- Mantener lenguaje chileno, profesional y ético.
- No prometer aprobación de beneficios, subsidios, prestaciones ni adjudicación de fondos.
- No pedir, recibir, almacenar ni registrar ClaveÚnica.
- No agregar formularios con datos sensibles sin backend seguro, consentimiento claro y controles de acceso.
- Evitar lenguaje como "te conseguimos beneficios" o cualquier promesa comercial agresiva.
- Priorizar componentes reutilizables, datos separados y cambios acotados.
- Mantener diseño limpio, responsivo, accesible y con buen contraste.
- Toda nueva sección debe considerar límites éticos del Trabajo Social y protección de datos.
- Verificar información de beneficios, trámites y organismos en fuentes oficiales antes de publicarla como vigente.
- Mantener el proyecto compatible con GitHub Pages y la base `/consulta-trabajo-social/`.
